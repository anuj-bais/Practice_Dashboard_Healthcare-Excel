# 🏥 Healthcare Data Analysis Dashboard | Excel Practice Project

## 📌 About the Project

This is a **Healthcare Data Analysis Dashboard** created using Microsoft Excel as part of my practice in Data Analytics.

The main purpose of this project is to practice and improve my skills in Excel, data analysis, data visualization, and dashboard development.

The dashboard provides an interactive overview of healthcare data, including patient information, billing, admission types, departments, and discharge status.

This is a learning project created for practice purposes.

## 🎯 Project Objectives

- Practice data cleaning and data preparation in Excel.
- Improve my understanding of Pivot Tables and Pivot Charts.
- Develop an interactive dashboard using Excel.
- Learn how to create meaningful KPIs.
- Practice analyzing healthcare data using visualizations.
- Improve my dashboard design and data storytelling skills.

## 📊 Dashboard Overview

The dashboard includes the following KPIs:

| KPI | Description |
|---|---|
| Total Patients | Total number of patient records |
| Average Stay Days | Average duration of patient stays |
| Average Bill | Average billing amount |
| Emergency Admission | Number of emergency admissions |

### 📈 Visualizations

The dashboard includes the following charts:

- Gender vs Bill
- Department vs Billing
- Admission Type vs Age Group
- Department vs Admission Type
- Discharge Status vs Admission Type & Gender
- Emergency Admissions by Day
- Emergency Admissions by Month

### 🎛️ Interactive Filters

The dashboard includes interactive slicers for:

- Age Group
- Gender
- Admission Type
- Discharge Status

These slicers allow users to filter the dashboard and explore different aspects of the healthcare data.
